#### Estados

O componente de card possui dois estados visuais (Default e Highlight), e não há interações do usuário (como hover, foco ou clique). Os estados são utilizados para chamar atenção para um determinado conteúdo dentro de uma lista ou grupo de cards.Card padrão (Padrão) com fundo sutil (neutro), utilizado como estado base ou inativo;Card destacado (Highlight) com fundo colorido translúcido, aplicado quando se deseja enfatizar o conteúdo — por exemplo, ao indicar que o card representa um item recente, importante ou com status ativo no momento.

Card Invoice é uma composição do componente Card (Template) da biblioteca de Design System. É utilizado para apresentar informações relacionadas a faturas, cobranças ou transações financeiras de forma clara, agrupada e visualmente padronizada. Ele permite a exibição de múltiplos dados descritivos com ênfase na categorização por meio de um tag de identificação colorida no topo do card. É ideal para seções de listagens financeiras, dashboards administrativos e fluxos de cobrança, proporcionando uma apresentação compacta, legível e facilmente interpretável de dados relacionados a contas.
