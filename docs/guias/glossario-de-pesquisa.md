# Glossário de Termos

| **Termo** | **Definição** |
| --- | --- |
| **Análise Heurística** | Avaliação de interface baseada em princípios de usabilidade pré-definidos (heurísticas) para identificar problemas de design. |
| **Anonimização** | Processo técnico que remove a possibilidade de identificar um indivíduo através de seus dados. |
| **Backlog de UX** | Lista de melhorias de design e usabilidade priorizadas com base em evidências de pesquisa. |
| **Benchmarking** | Comparação de produtos ou serviços com concorrentes para identificar padrões e oportunidades de melhoria. |
| **Card Sorting** | Técnica de pesquisa para entender como os usuários categorizam e organizam informações. |
| **Cliente Oculto** | Método onde um pesquisador simula ser um cliente real para avaliar a jornada e a qualidade do atendimento ou serviço. |
| **Critérios de Sucesso** | Definições claras que determinam se os objetivos da pesquisa foram atingidos. |
| **Dados Sensíveis** | Informações que exigem proteção especial pela LGPD, como origem racial ou convicções. |
| **Desk Research** | Pesquisa secundária baseada em dados já existentes, como relatórios internos ou artigos de mercado. |
| **Estudo de Diário** | Método de coleta de dados onde o usuário registra suas experiências ao longo de um período de tempo. |
| **Funil de Conversão** | Mapeamento dos passos que o usuário percorre até completar um objetivo de negócio. |
| **Grupos Focais** | Discussão mediada com um pequeno grupo de usuários sobre temas ou conceitos específicos. |
| **HMW (How Might We)** | Técnica para transformar problemas encontrados em oportunidades de solução ('Como poderíamos...'). |
| **Ideação co-criativa** | Workshops colaborativos (ex: Design Sprints) que reúnem diferentes perspectivas para gerar e refinar soluções de forma conjunta. |
| **Incentivo** | Compensação oferecida ao participante da pesquisa, como brindes ou cupons. |
| **Insight** | Descoberta profunda sobre o usuário que direciona decisões de design e priorização de backlog. |
| **Jornada do Usuário** | Visualização das etapas, pontos de contato e emoções do usuário durante o uso de um serviço. |
| **LGPD (Pesquisa)** | Conjunto de regras sobre coleta, tratamento e armazenamento de dados pessoais dos participantes. |
| **Matriz CSD** | Ferramenta para organizar Certezas, Suposições e Dúvidas no início de um projeto. |
| **Matriz Impacto x Esforço** | Ferramenta de priorização que cruza o valor entregue ao usuário/negócio com a dificuldade técnica de implementação. |
| **NPS (Net Promoter Score)** | Métrica que mensura a lealdade e a probabilidade de recomendação do produto pelo usuário. |
| **Persona** | Arquétipo baseado em dados reais que representa as necessidades, objetivos e comportamentos de um grupo de usuários. |
| **Pesquisa Qualitativa** | Focada em entender o 'porquê' por trás dos comportamentos e motivações por meio de observação direta. |
| **Pesquisa Quantitativa** | Focada em gerar dados numéricos e estatísticas para responder 'quanto' ou 'com que frequência' algo ocorre. |
| **Product Discovery** | Processo de exploração para entender um problema e validar hipóteses antes de construir uma solução. |
| **Prototipagem de Baixa Fidelidade** | Representação simples e rápida de uma interface para validar fluxos e conceitos iniciais. |
| **Protótipo** | Representação funcional ou visual de um produto para testar fluxos, usabilidade e conceitos com usuários. |
| **Recrutamento** | Processo de filtrar e selecionar participantes que se encaixam no perfil desejado para a pesquisa. |
| **Repositório de Pesquisa** | Local centralizado para armazenamento, consulta e compartilhamento de descobertas passadas. |
| **Roadmap de Pesquisa** | Planejamento cronológico das atividades de pesquisa alinhadas ao desenvolvimento do produto. |
| **Screening** | Questionário de triagem utilizado para selecionar participantes que atendam aos critérios de pesquisa. |
| **Service Blueprint** | Diagrama que detalha a jornada do usuário e os processos internos que a sustentam. |
| **Shadowing** | Técnica de observação direta do usuário realizando suas tarefas em seu ambiente natural. |
| **Stakeholder Interview** | Entrevista com pessoas-chave do negócio para alinhar objetivos e expectativas do projeto. |
| **Stakeholders Map** | Visualização dos atores internos e externos que possuem interesse, influência ou impacto no projeto. |
| **SUS (System Usability Scale)** | Questionário padronizado de 10 itens para medir a percepção subjetiva de usabilidade. |
| **Taxa de Sucesso** | Porcentagem de usuários que conseguem completar uma tarefa específica sem erros críticos. |
| **TCLE** | Termo de Consentimento Livre e Esclarecido; documento onde o usuário autoriza a participação e gravação. |
| **Telemetria** | Coleta automática de dados sobre o uso do software para validar eventos quantitativos. |
| **Teste A/B** | Método de comparação entre duas versões de uma interface para medir qual performa melhor. |
| **Teste de Usabilidade** | Avaliação de um produto com usuários reais para identificar problemas de interação e navegação. |
| **Teste de Árvore** | Método para avaliar especificamente a eficácia da hierarquia e estrutura de navegação. |
| **Triangulação de Dados** | Uso de múltiplos métodos ou fontes de dados para validar uma mesma descoberta ou hipótese. |
| **UX Research (UXR)** | Estudo sistemático dos usuários e seus requisitos para adicionar contexto e insights ao processo de design. |
| **VOC (Voice of the Customer)** | Metodologia de pesquisa focada em capturar e organizar sistematicamente as necessidades e expectativas reais do cliente. |
