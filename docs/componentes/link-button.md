# Link Button

O componente Link é fundamental para a navegação em interfaces digitais, permitindo que usuários acessem páginas, seções ou recursos relacionados.

## Overview

https://www.figma.com/design/CKUcFnQotY9rWVBfOUtxq8/Winthor---UI-KIT-Delphi--Evolu%C3%A7%C3%A3o--Pr%C3%A9-publica%C3%A7%C3%A3o-?node-id=1528-4076&t=cQTb9S6kABOwBlKW-4

Ele é comumente associado a conteúdos textuais, mas também pode aparecer em barras de ação ou ao final de parágrafos, assumindo uma função de navegação sem necessariamente estar embutido no corpo do texto. Diferente de botões, que representam ações imediatas do sistema, os links indicam caminhos e continuidade na experiência do usuário.

#### Somente rótulo

Ele deve ser usado para ações secundárias ou de navegação que não exigem destaque visual elevado, mantendo a interface limpa e discreta. A mensagem do botão deve ser clara e direta, informando exatamente o que o usuário encontrará ou acionará ao interagir. O texto deve ser curto, acionável e manter consistência com o tom de voz do produto, evitando ambiguidade ou termos vagos. Seu uso é ideal em barras de ação, rodapés ou contextos onde o foco visual deve permanecer em outras ações prioritárias.

> ⚠️ Revisar imagem: variação somente rótulo

#### Com ícones

O ícone deve ser posicionado à esquerda do texto e escolhido com base em sua clareza semântica — não deve ser decorativo nem redundante. É ideal para ações secundárias que ainda exigem reconhecimento rápido, como "Imprimir", "Visualizar" ou "Baixar", mantendo a consistência com o propósito e estilo do design system.

> ⚠️ Revisar imagem: variação com ícones

### Restrições de uso

#### Não utilize o Link Button como substituto de botões secundários ou terciários.

Evite usar o componente de Link Button com a intenção de representar ações secundárias (como "Cancelar") ou terciárias (como "Voltar", "Fechar", etc.), utilize as variantes definidas para componente Button para essa funcão.

> ⚠️ Revisar imagem: restrição de uso como botão secundário
