# Tooltip

O componente Tooltip geralmente aparece como uma caixa de texto flutuante que fornece detalhes, dicas ou explicações contextuais, sendo ativado ao passar o mouse ou focar em um elemento.

#### Limite de texto

O limite de linhas no Tooltip deve ser de 4 linhas e evite textos longos. Lembre-se que inicialmente o conteúdo estará sempre oculto para o usuário.
