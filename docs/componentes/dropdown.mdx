# Dropdown

O Dropdown é utilizado para exibir uma lista de opções de forma compacta, permitindo que o usuário selecione uma única opção a partir de uma lista suspensa.

É ideal para interfaces que exigem economia de espaço e clareza na apresentação de múltiplas alternativas, mantendo a experiência do usuário simples, objetiva e intuitiva. O componente é frequentemente aplicado em formulários, filtros, menus de ações e seleções contextuais, proporcionando uma navegação limpa e organizada. Sua aparência discreta contribui para interfaces mais minimalistas e funcionais.

**Diferença entre Dropdown e Combobox**

Enquanto o Dropdown limita-se à seleção de uma opção previamente definida na lista, o Combobox permite ao usuário digitar um valor livremente, com ou sem sugestão baseada nas opções existentes (autocompletável). Ou seja, o Dropdown é estático e direto; o Combobox é mais flexível e interativo.

### Variantes

#### Tamanho

O componente está disponível em dois tamanhos: LG e MD. A única diferença visual entre os tamanhos está no campo de seleção (altura e padding) e tamanho de fonte. A lista de opções mantém o mesmo tamanho de fonte e espaçamento independentemente do tamanho do dropdown.

#### Dropdown e conteúdo

Dropdowns simples são componentes utilizados para apresentar uma lista compacta de opções, visível somente após a interação do usuário. São ideais para escolhas diretas onde não há necessidade de digitação ou busca. O conteúdo do dropdown deve ser claro, conciso e conter uma quantidade limitada de itens para manter a usabilidade. Esse padrão é recomendado quando as opções são conhecidas, previsíveis e não exigem filtro dinâmico.
