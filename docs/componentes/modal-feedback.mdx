# Modal Feedback

Modal Feedback é uma composição do componente Card (Template) da biblioteca de Design System. É um componente dedicado a comunicar mensagens de retorno ao usuário, geralmente após uma ação executada, como envio de formulário, conclusão de processo ou ocorrência de erro. Ele deve ser utilizado para destacar de forma clara e objetiva o resultado de uma interação, oferecendo contexto visual coerente com o tipo de mensagem, como sucesso, alerta ou erro e, quando necessário, apresentar ações complementares que incentivem a continuidade da jornada do usuário.

## Guidelines

### Anatomia

Como é um componente Composition, sua estrutura é composta por elementos da biblioteca, permitindo combinações a partir dos próprios componentes e variações.

### Variantes

#### Tamanho único

Disponível apenas em 1 tamanho.

> ⚠️ Revisar imagem: tamanho único do Modal Feedback

#### Feedbacks

Aplique cada Modal Feedback conforme a situação do usuário:

Brand para mensagens institucionais ou mensagens do software. Neutral para comunicações neutras ou estados vazios. Informative para contextualizar processos ou orientar o usuário. Processing para ações que têm continuidade assíncrona ou com término não definido. Date Success para agendamentos com data. Success para confirmar ações concluídas corretamente. Warning para chamar atenção a situações que exigem cuidado. Alert para indicar falhas críticas que impedem a continuidade da ação.Mantenha consistência no tom e na hierarquia visual de cada mensagem, garantindo clareza e comunicação eficiente dentro do modal.
