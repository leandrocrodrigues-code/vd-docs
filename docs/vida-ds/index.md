# Vida DS

Um Design System reúne princípios, padrões e componentes reutilizáveis para orientar a criação de interfaces. No **VIDA DS**, designers e desenvolvedores encontram fundamentos e orientações para construir novas experiências e modernizar gradualmente os sistemas legados, sem precisar reconstruir tudo de uma só vez.

## O que tem aqui

- **[Componentes](./componentes/)** — Botões, campos, cards e demais blocos reutilizáveis, com uso, variações e código pronto no Storybook (POUi e Delphi).
- **[Estilos](./estilos/)** — Cores (Light e Dark), tipografia, espaçamento, marca e grid. As páginas técnicas são geradas direto dos tokens do Figma.
- **[Tokens](./tokens/)** — Os tokens brutos em JSON e como consumir no seu projeto (variáveis CSS, imports, etc.).
- **[Comportamentos](./comportamentos/)** — Padrões de animação, motion, timing e microinterações (em construção).
