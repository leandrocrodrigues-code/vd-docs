# Estilos

Os Estilos reúnem as decisões visuais que orientam todo o Vida DS: **cores**, **tipografia**, **espaçamento**, **marca** e **grid**.

- **Cores** e **Tipografia** e **Espaçamento** — geradas direto dos [tokens](../tokens/) do Figma. Não editar à mão.
- **Marca** e **Grid** — texto humano, editável.
- **Cores (uso)** e **Tipografia (uso)** — quando aplicar cada cor / estilo.

Antes de uma interface ganhar forma, existem decisões que garantem clareza, equilíbrio e identidade. Os Estilos estabelecem essa base e ajudam produtos diferentes a evoluírem seguindo uma direção comum.
