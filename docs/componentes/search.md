# Search

Search é utilizado para permitir que os usuários encontrem rapidamente informações em uma interface, seja por meio de uma barra de pesquisa, campo de texto ou funcionalidades de filtro.

## Overview

https://www.figma.com/design/CKUcFnQotY9rWVBfOUtxq8/Winthor---UI-KIT-Delphi--Evolu%C3%A7%C3%A3o--Pr%C3%A9-publica%C3%A7%C3%A3o-?node-id=321-8197&t=cQTb9S6kABOwBlKW-11

O Search é essencial em interfaces onde há uma grande quantidade de dados ou opções, ajudando a melhorar a experiência do usuário ao proporcionar uma maneira eficiente de localizar conteúdo específico.

#### Busca na página ou ocorrência

Componente utilizado para localizar e percorrer palavras ou expressões dentro do conteúdo visível da página atual. Fica fixo no topo e exibe contagem de ocorrências encontradas, com navegação sequencial por setas. Ideal para interfaces com grandes volumes de texto ou tabelas densas.
