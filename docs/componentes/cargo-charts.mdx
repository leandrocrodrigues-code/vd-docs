# Cargo Charts

É um componente Composition da biblioteca de Design System. O Cargo Chart é um componente visual projetado para representar a capacidade ou o nível de ocupação de cargas de forma ilustrativa e intuitiva. Utilizando ícones de caminhões preenchidos proporcionalmente, ele permite identificar rapidamente o percentual de utilização de cada unidade ou categoria. Esse recurso é ideal para cenários de logística, transporte ou gestão de estoque, facilitando a comparação entre múltiplos elementos e ajudando na tomada de decisão. Seu foco é comunicar de forma clara o status de carregamento, sem a intenção de apresentar números avulsos e complexos.

#### Tamanho único

> ⚠️ Revisar imagem: Cargo Chart em tamanho único

#### Variações

É fornecido dois tipos de gráficos em barras: o segmentado e o simples. Por padrão eles podem ser dimensionados até 10 barras, e para o segmentado até 14 cores.

> ⚠️ Revisar imagem: variações segmentada e simples do Cargo Chart

#### Color Charts

Siga a ordem definida para as cores de gráficos e não altere as cores padrões. São 14 cores, incluindo as definidas para feedback que também são utilizadas.
