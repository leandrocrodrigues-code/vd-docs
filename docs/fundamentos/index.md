# Fundamentos

Os Fundamentos reúnem as decisões visuais e estruturais que orientam todo o VIDA DS, como cores, tipografia, espaçamentos, grid e princípios de experiência.

> ⚠️ Revisar imagem: ilustração de abertura dos Fundamentos

**Onde tudo começa**

Antes de uma interface ganhar forma, existem decisões que garantem clareza, equilíbrio e identidade. Os Fundamentos estabelecem essa base e ajudam diferentes produtos a evoluírem seguindo uma direção comum. Navegue entre nossas bibliotecas de [Cores](https://zeroheight.com/422b6358a/p/9201d2), [Grid](https://zeroheight.com/422b6358a/p/524731) e [Tipografia](https://zeroheight.com/422b6358a/p/66de98)
