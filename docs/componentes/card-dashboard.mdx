Card Dashboard é uma composição do componente Card (Template) da biblioteca de Design System. É um componente visual compacto e informativo, ideal para exibição de indicadores-chave de desempenho (KPIs) em visões gerenciais ou operacionais do sistema. Ele combina um valor principal em destaque com informações complementares como ícone de categoria, variação percentual (positiva ou negativa), valor de suporte e texto explicativo. Seu uso é voltado para transmitir rapidamente o status de métricas financeiras, operacionais ou comerciais, com foco em legibilidade e síntese. O layout modular permite adaptações conforme o contexto, mantendo sempre uma hierarquia clara entre os dados principais e seus desdobramentos.

## Guidelines

### Anatomia

#### Contextual menu

Os cards podem incluir um menu contextual acessível por meio de um ícone no canto superior direito. Esse menu permite associar ações adicionais ao componente, oferecendo flexibilidade para adaptar funcionalidades conforme o contexto de uso. A inclusão do menu é opcional e deve seguir o padrão visual de sobreposição, garantindo consistência com os demais elementos da interface.
