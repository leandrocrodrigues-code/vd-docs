# Tag

As Tags funcionam como marcadores estáticos ou levemente interativos, geralmente associados a categorias, status ou palavras-chave. Têm como foco principal a identificação, e não a ação. Seu uso ajuda o usuário a reconhecer rapidamente o contexto ou o agrupamento de um item, como um tipo de documento, status de projeto ou área temática.

#### Feedback

A Tag pode ser utilizada como elemento de feedback visual, comunicando estados, resultados ou alertas de forma rápida e destacada. Nesse uso, serve para indicar informações como sucesso, erro, aviso ou status de processos, reforçando a clareza e a percepção imediata do usuário sobre a situação apresentada.

> ⚠️ Revisar imagem: variações de feedback da Tag

#### Conteúdo

A Tag também pode ser empregada para exibir conteúdos complementares, como números, previsões ou informações secundárias que apoiam a compreensão do contexto principal. Nesse caso, atua como um marcador informativo, ajudando a destacar dados relevantes sem sobrecarregar a interface.

> ⚠️ Revisar imagem: Tag usada como conteúdo complementar

### Restrições de uso

#### Não utilize tags como chips e vice-versa

A distinção entre tags e chips é importante para manter a clareza semântica: enquanto chips sugerem uma possível interação (como seleção ou remoção), as tags devem ser utilizadas apenas para rotulagem clara e direta, com ou sem ação secundária como filtro.
