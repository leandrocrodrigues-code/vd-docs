É um componente Composition da biblioteca de Design System. O Donut Chart é um componente visual usado para representar a composição de um conjunto de dados em formato circular, destacando a proporção entre suas partes e o total. Sua principal vantagem é permitir uma leitura rápida das relações entre categorias, mantendo o contexto geral no centro do gráfico. Este componente é flexível e pode exibir tanto valores absolutos quanto percentuais, dependendo do objetivo de análise. As cores aplicadas às fatias devem seguir um padrão consistente para reforçar a associação visual (por exemplo, verde para ativos e vermelho para inativos). É indicado para cenários em que se deseja comparar distribuições e, ao mesmo tempo, preservar a noção de total, como no acompanhamento de status de itens, alocação de recursos ou segmentação de públicos. O Framework usado para a renderização dos gráficos é o Echart ([https://echarts.apache.org/examples/en/index.html](https://echarts.apache.org/examples/en/index.html)). Usamos a escala de cor hierárquica definida em Fundamentals do Design System.

### Variantes

#### Tamanho único

Disponível apenas em 1 tamanho.

> ⚠️ Revisar imagem: Donut Chart em tamanho único

#### Variações

É fornecido dois tipos de gráficos em barras: o segmentado e o simples. Por padrão eles podem ser dimensionados até 10 barras, e para o segmentado até 14 cores.

> ⚠️ Revisar imagem: variações do Donut Chart

#### Color Charts

Siga a ordem definida para as cores de gráficos e não altere as cores padrões. São 14 cores, incluindo as definidas para feedback que também são utilizadas.

> ⚠️ Revisar imagem: paleta de 14 cores para Donut Chart

#### Usos

O valor central, que mostra o total, ajuda a manter o contexto geral da informação, enquanto cores contrastantes e consistentes (verde para ativos, vermelho para inativos) facilitam a leitura e compreensão. É importante sempre alinhar o uso do gráfico à natureza dos dados e ao insight que se deseja. Gerar métricas absolutas são úteis para gestão de estoque ou capacidade, enquanto percentuais são mais eficazes para análise comparativa e tendências.

> ⚠️ Revisar imagem: exemplos de uso do Donut Chart

#### Actions

As cores são predefinidas pelo Design System, portanto não altere os padrões. São 14 cores, incluindo as definidas para feedback que também são utilizadas.
