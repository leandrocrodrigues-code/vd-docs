# Text Area

O Text Area é um campo de entrada de múltiplas linhas, ideal para capturar blocos maiores de texto, como descrições, comentários, mensagens ou observações.

## Overview

https://www.figma.com/design/CKUcFnQotY9rWVBfOUtxq8/Winthor---UI-KIT-Delphi--Evolu%C3%A7%C3%A3o--Pr%C3%A9-publica%C3%A7%C3%A3o-?node-id=316-4058&t=cQTb9S6kABOwBlKW-11

Ele oferece suporte a altura dinâmica, expandindo conforme o conteúdo é digitado, garantindo melhor visibilidade e conforto durante a escrita. Além disso, o Text Area contribui para uma melhor experiência em contextos que exigem respostas abertas ou mais elaboradas, mantendo a legibilidade mesmo com grandes volumes de texto.

**Diferença entre Text Area e Text Input:** Text Area permite várias linhas, sendo mais indicado para conteúdo extenso ou descritivo, enquanto o Text Input é restrito a uma linha e usado para entradas curtas.
