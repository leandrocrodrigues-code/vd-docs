O Combobox combina as funcionalidades de um campo de texto com uma lista suspensa de opções, permitindo que o usuário selecione um item da lista ou digite um valor manualmente. É especialmente útil em situações em que as opções disponíveis são muitas, dinâmicas ou quando se deseja oferecer maior flexibilidade na entrada de dados. Esse componente melhora a eficiência da interação ao permitir autocompletar, pesquisa rápida ou sugestões conforme o usuário digita, tornando a seleção mais fluida mesmo em listas extensas.

**Diferença entre Combobox e Dropdown**

O Combobox oferece liberdade para entrada manual, com ou sem apoio da lista, enquanto o Dropdown limita a escolha a valores pré-definidos, ou seja, o Dropdown é restritivo e direto, enquanto o Combobox é mais interativo e adaptável ao contexto do usuário.

#### Busca no campo de seleção (Combobox com campo editável)

O Combobox com campo de busca permite que o usuário digite diretamente no campo de entrada para filtrar as opções disponíveis. Essa variação é útil para listas extensas ou quando o usuário já sabe parte do valor que deseja encontrar. Ele combina os comportamentos de um campo de texto com uma lista suspensa, otimizando a navegação e reduzindo o tempo de busca. Ideal para seleções em que a previsibilidade ou familiaridade com os itens facilita a interação.

> ⚠️ Revisar imagem: Combobox com campo editável de busca

#### Busca dentro da Combobox

Nesta variação, o Combobox exibe um campo de busca apenas após o usuário abrir a lista suspensa. O campo de filtro é posicionado dentro do dropdown, permitindo que o usuário refine os resultados exibidos sem editar o valor diretamente no campo principal. Essa abordagem é útil quando a seleção deve ser feita exclusivamente a partir da lista apresentada, mantendo a entrada protegida de alterações manuais.
