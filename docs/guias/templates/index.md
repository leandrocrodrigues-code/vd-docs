# Templates

Os templates oferecem uma estrutura inicial baseada em soluções já validadas. Eles podem ser adaptados ao contexto de cada produto sem perder os padrões e comportamentos que sustentam a experiência.

> ⚠️ Revisar imagem: ilustração de abertura da seção Templates

**Estruturas para começar**

Templates são estruturas reutilizáveis para páginas e fluxos recorrentes, criadas para acelerar o trabalho e manter padrões consistentes entre diferentes produtos.

Contudo, aqui é agrupado todos os componentes e composições em estruturas prontas para diferentes contextos, como [drawers](https://zeroheight.com/422b6358a/p/23e221), seções, páginas e fluxos. Eles oferecem um ponto de partida consistente, que pode ser adaptado às necessidades de cada produto.
