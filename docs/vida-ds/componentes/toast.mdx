# Toast

O Toast surge de forma flutuante e pode desaparecer automaticamente após alguns segundos ou ser fixado. Ideal para informar o usuário sobre ações concluídas, alertas ou mudanças de estado sem interromper o fluxo de uso. Os toasts devem ser objetivos, breves e autoexplicativos, podendo incluir ícones e ações secundárias quando necessário.
