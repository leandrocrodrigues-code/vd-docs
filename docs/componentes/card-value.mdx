# Card Value

Card Value é uma composição do componente Card (Template) da biblioteca de Design System. Tem como objetivo apresentar valores financeiros ou percentuais de forma destacada e comparativa, permitindo que usuário faça a análise rápida de métricas e indicadores de desempenho. Ele é ideal para dashboards, relatórios e áreas de monitoramento de metas ou status de indicadores-chave. Promove clareza e objetividade na apresentação de dados quantitativos, com foco em performance, comparação e tomada de decisão.

#### Estados

Card Value é utilizado para apresentar informações numéricas, com destaque para o valor principal e seus respectivos feedbacks de desempenho. Ele é composto por dois tipos principais de blocos: Main e Feedback. Esses estados são aplicados em contextos como dashboards de indicadores, metas comerciais, relatórios operacionais e análises de desempenho.

> ⚠️ Revisar imagem: blocos main e feedback do card value

#### Feedback

Os feedbacks deve ser sempre exibidos em conjunto com o card principal (Main). Ele não é autônomo e depende do contexto do valor principal para fazer sentido.Ou seja, ele representa um complemento interpretativo ao valor monetário ou percentual destacado no card da esquerda. Separadamente, pode causar ambiguidade de leitura.
